# TEMIDA PARS

Автоматический сбор, тест и переименование V2Ray-конфигов.

## Что делает

- Каждый час собирает конфиги из 9 источников
- Декодирует Base64-подписки, парсит Xray-JSON
- Тестирует через `python-v2ray` (реальный URL-тест)
- Оставляет только конфиги с задержкой <= 250 мс
- Переименовывает: `BY Belarus 01 TEMIDA PARS`
- Сохраняет в `temida.txt` (по одному URI на строку)

## Готовый файл

Смотрите [`temida.txt`](./temida.txt) - обновляется каждый час.
